# 数据安全与合规说明

## 使用边界

本项目仅处理脱敏或经授权的教学/测试数据。AI 输出必须由具备权限的采购、业务、法务或审计人员复核，不能自动触发签约、付款、审批或问责。

## 已实现控制

- 所有写入经 `Settings.writable_path` 限制在项目根目录内；上传文件进入 `outputs/sessions/<随机会话 ID>`。
- PDF 扩展名、签名、大小、页数和加密状态均在解析前验证；页面在本地渲染并由本地 OCR 识别，原始证据可通过页码、bbox、chunk ID 和哈希回溯。
- 默认 `rules` 引擎完全离线；外部选项显示 provider、精确模型名、base URL 和“数据出域”，且必须勾选“仅上传脱敏/授权测试数据并同意发送”后才能调用。
- API Key 仅从本地 `.env` 注入，使用 `SecretStr`，`.env` 被忽略；示例配置不含真实凭证。
- 日志和机器输出不记录完整合同正文或密钥；模型原始响应仅写入项目内受控目录。
- 未核验 gold 无法计算正式指标，盲测样本无法进入训练标签流程。
- Web、JSON、DOCX 和 PDF 均醒目标记“教学模拟/测试数据”，报告记录运行 ID、输入 SHA-256、模型/提示词版本、证据校验和人工复核状态。
- Web 错误不会丢弃已完成的解析阶段。当前会话清理必须显示 32 位会话 ID 和完整目标目录、二次确认，并通过精确路径校验拒绝会话根目录或其他目录。

## 外部模型启用前置条件

启用外部模型前，应由数据所有者和安全/合规职责人完成数据分类分级、最小化、脱敏效果、供应商、传输与存储地域、日志留存、二次使用/训练条款、删除能力、事件响应和退出机制评估。必须使用 TLS，限制出站目的地与密钥权限，设置费用/速率上限，并通过抽样确认请求和响应没有超出授权字段。

如果合同数据不允许出域，应使用经批准的内网推理服务或私有化部署。私有化不自动等于安全：仍需网络隔离、身份认证、最小权限、密钥轮换、镜像和依赖治理、补丁管理、审计日志、备份恢复、容量规划以及模型/提示词变更审批。

## 生产化仍需补齐

- 企业身份系统、按项目/角色授权、双人复核和审批签章。
- 会话过期策略；当前原型支持用户手动清理当前具体会话，但不自动删除，避免误删审计证据。
- 静态加密、企业 KMS、对象级访问控制、集中审计与异常告警。
- DLP/敏感字段识别、正文脱敏和最小上下文发送。
- 模型、提示词、规则、数据和人工决定的完整版本血缘。
- 红队测试、越权/提示注入测试、误报漏报阈值和应急回退。
- 结合机构实际适用制度开展法律、数据、模型和科技风险评估。

本文件提供技术控制清单，不构成对具体机构或具体数据的法律意见。
