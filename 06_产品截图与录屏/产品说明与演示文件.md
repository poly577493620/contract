# 产品说明与演示文件

## 产品简介

“智审合规助手”是采购结果与采购合同的双文档质检 MVP。用户分别上传两份 PDF 后，系统对完整页面进行本地 OCR，按条款比较采购要求与合同承接情况，展示一致、缺失或差异结论及可回查证据，并可导出 JSON、DOCX、PDF 报告。系统提供离线规则基线和经授权的外部模型端点，所有结果均要求人工复核。

## 演示闭环

`上传采购结果与合同 → PDF 校验与页面 OCR → 选择规则或模型 → 条款审核 → 查看风险与证据 → 筛选人工复核项 → 导出报告`
